## Main section

ACA Virus Detector And Vaccin (1987-1988) is an antivirus program written by Anti Copyright Association that detects only the ACA virus, which can be written to disk using this same virus detector. Let's take a look at the interface.
## Interface

(photo 3)
1. We can check the disk with the F1 key, which will display one of three options:
1. The disk is infected (photo 0)
2. The disk is clean (photo 1)
3. The disk is vaccinated with the ACA vaccine (photo 2)
2. We can write the ACA vaccine to the disk with the F2 key.
3. We can infect the ACA disk with a virus with the F6 key if we enter "EVOT" with CapsLock enabled.
4. We can exit to the desktop with the F10 key.
