## Basic Information
* Author: George R. Woodside
* Program language: English
* Version 3.84
* Creation date: April 1991
* Can detect bootsectors

## Main Text
When we start the program, we are greeted with a warning (photo 0). After that, we select drive A/B and enter the main menu (photo 1). At the top, we see tabs... Let's quickly go through them!

## Main Functionality
You can check drive A/B.
You can view the boot sector in HEX and ASCII simultaneously! Function: Show
You can print all data or only the boot sector! Function: Print
You can write the boot sector to a file! Function: File
You can kill the boot sector! Function: Kill
You can vaccinate the boot sector! Function: Guard
You can repair the boot sector if the BPB is damaged! Function: Repair
You can exit the program! Function: Quit

## Boot Sector Information
If Vkiller recognizes a boot sector, you can find out information about it by pressing the "Boot Sector Recognized!" button.
If the boot sector is the most ordinary one, you will see a smiley like this (photo 5).
