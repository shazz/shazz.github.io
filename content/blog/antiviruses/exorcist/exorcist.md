# Main Text
EXORCIST III is a professional antivirus for Atari ST, developed by IKI & Caledonia as a continuation of the popular EXORCIST series. The program has expanded capabilities compared to previous versions. The cursor is in the shape of a skull.

### What are they doing?

1. Exit the program

![photo]({attach}exorcist_photo_1.png)

![photo]({attach}exorcist_photo_2.png)

2. Disk information

    1. Sides can be toggled (1-2)

    2. Tracks can be increased and decreased

    3. Sectors can be increased and decreased

3. Boot sector information from .LIB file

    1. Sides can be toggled (1-2)

    2. Tracks can be increased and decreased

    3. Sectors can be increased and decreased

4. Can view boot sector in ASCII or as assembly code

![photo]({attach}exorcist_photo_3.png)

5. If you click this button, the text will briefly change to "Exorcist in action"

6. Changes the boot sector's checksum to make it Executable/Not Executable

7. Can modify the boot sector. For example, delete it

![photo]({attach}exorcist_photo_4.png)

9. Check boot sector and display its type, sides, tracks, and sectors

10. Load boot sector/Library .LIB

11. We can rename a boot sector and save it with that name.

12. We can select a boot sector from the library and view it by clicking the right mouse button

13. Merge .LIB libraries

14. Save .LIB library

15. Integrate .PRG file

16. Allows moving boot sectors within the library

17. Clear .LIB library
